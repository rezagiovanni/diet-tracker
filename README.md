# Diet Tracker 🍽️

Dashboard diet — tracking makanan, workout, berat badan, dan komposisi tubuh.

**Stack:** FastAPI + React + BigQuery + Cloud Run

## Fitur
- **Card:** Kalori & protein hari ini (target 1300 kcal / 90g protein)
- **Line graph:** Kalori & protein 7 hari terakhir
- **Line graph:** Berat & Body Fat %
- **Pie chart:** Komposisi Protein/Carbs/Fat hari ini

## Deploy
Push ke `main` → auto-deploy ke Cloud Run via GitHub Actions.
